# تطبيق الهاتف: تلاوات المسجد الكبير (Android Mobile App)

تطبيق React Native مخصص لأندرويد مبني باستخدام Expo، يدعم تشغيل التلاوات في الخلفية، حفظ موضع الاستماع، التنزيل بدون إنترنت، وتصفح المجلدات العادية ومجلدات السنوات المرتبة بالأشهر تلقائياً.

## المميزات

- واجهة عربية أصيلة تدعم RTL بالكامل (`I18nManager.forceRTL(true)`).
- مظهر مخصص ومحسّن للعين مع زخارف هندسية إسلامية خفيفة (وضع فاتح `#F6F8F3` ووضع داكن كحلي عميق).
- مشغل صوتيات احترافي يعمل في الخلفية وشاشة القفل عبر `react-native-track-player`.
- تشغيل بدون إنترنت عبر تنزيل المقاطع الصوتية إلى مجلد التطبيق الخاص.
- تصفح المجلدات المتفرعة بأي عمق والبحث الفوري داخل نطاق أي مجلد.
- تسجيل الدخول بحساب Google لمزامنة المفضلة، مع إمكانية التصفح والاستماع الكامل كضيف بدون حساب.
- تغذية رأسية للمقاطع المرئية القصيرة (Reels) مع روابط مباشرة للتطبيقات الأصلية.

## أوامر التشغيل والبناء

```bash
cd app
npm install

# تشغيل خادم التطوير
npm run start

# بناء ملف APK مجاناً عبر Expo EAS
npx eas build -p android --profile preview

# أو توليد مشروع أندرويد محلياً
npx expo prebuild -p android
```
