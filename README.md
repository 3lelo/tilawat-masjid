# تلاوات المسجد الكبير (Tilawat Almasjid Alkabeer)

مشروع متكامل ومفتوح المصدر لإدارة ونشر تلاوات القرآن الكريم، وخطب الجمعة، والدروس، والمقاطع المرئية القصيرة (Reels) الخاصة بالمسجد، مع تشغيل الصوتيات في الخلفية وتحميلها للاستماع بدون إنترنت.

## هيكلة المشروع

```
tilawat/
├── app/                  # تطبيق الهاتف (React Native + Expo Android APK)
├── admin-web/            # لوحة التحكم الإدارية للموقع والهاتف (Next.js / Vercel)
├── supabase/             # مخطط قاعدة البيانات (Migrations & Seed SQL)
├── workers/              # خدمات Cloudflare Workers (Keep-Alive Cron)
├── .github/workflows/    # سير عمل التحويل التلقائي للصوتيات عبر FFmpeg
└── SETUP.md              # دليل الإعداد خطوة بخطوة للخدمات المجانية
```

## المميزات الأساسية

- **مجاني 100% مدى الحياة**: لا يتطلب أي اشتراك مدفوع (Supabase + Cloudflare R2 + Vercel + GitHub Actions + Expo EAS).
- **تطبيق جوال مخصص لأندرويد**: واجهة عربية كاملة (RTL)، دعم الوضعين الفاتح والداكن، وزخارف إسلامية هادئة.
- **مشغل صوت احترافي**: تشغيل في الخلفية، تحكم من شاشة القفل والإشعارات، تسريع الصوت، مؤقت نوم، وحفظ تلقائي لموضع الاستماع.
- **تنزيل واستماع بدون إنترنت**: إمكانية تنزيل التلاوات وتشغيلها أوفلاين.
- **مجلدات متداخلة وترتيب حسب الأشهر**: دعم المجلدات العادية ومجلدات السنوات المرتبة بالأشهر تلقائياً (`year_month`).
- **بحث عربي فوري فائق الدقة**: تطبيع شامل للحروف العربية وإزالة التشكيل ومطابقة بالتشابه (Trigrams).
- **تغذية مرئية للمقاطع القصيرة (Reels)**: عرض مقاطع YouTube Shorts و TikTok و Instagram بانسيابية.
- **معالجة صوتية تلقائية**: تحويل الملفات المرفوعة إلى صيغة صوتية خفيفة عالية الجودة (48kbps AAC/m4a) بدون أي تدخل تقني من المسؤول.
