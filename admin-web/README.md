# لوحة التحكم الإدارية: تلاوات المسجد الكبير (Admin Web Panel)

لوحة تحكم إدارية متجاوبة مبنية بواسطة Next.js ومصممة خصيصاً للعمل بسلاسة على الهواتف الذكية والحواسيب. تتيح للمشرفين إدارة المجلدات والشجرة المتفرعة، رفع التسجيلات الصوتية والمرئية مباشرة إلى Cloudflare R2، وتتبع المعالجة والتحويل التلقائي (FFmpeg)، وإدارة المقاطع القصيرة (Reels).

## المميزات

- تصميم عربي متجاوب بالكامل (RTL) مع عناصر تحكم وأزرار كبيرة مريحة للاستخدام من شاشات اللمس في الهواتف.
- تسجيل دخول آمن بحساب Google عبر Supabase مع التحقق من صلاحيات المدير (`profiles.role = 'admin'`).
- رفع مباشر للملفات الكبيرة (حتى ساعتين) إلى Cloudflare R2 باستخدام روابط رفع موقّعة مسبقاً (Presigned URLs) لتجنب قيود خوادم Vercel Serverless.
- تتبع حالة التحويل التلقائي في الوقت الفعلي (`processing` -> `ready` / `failed`).
- إدارة شجرة المجلدات المتداخلة بأي عمق ودعم مجلدات السنوات المرتبة بالأشهر (`year_month`).
- حذف الملفات مع التنظيف التلقائي للأصل والملف المضغوط من سلة R2.

## أوامر التشغيل والنشر

```bash
cd admin-web
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء المشروع للإنتاج
npm run build
```

تُنشر اللوحة مجاناً على منصة Vercel بنطاق `*.vercel.app` الافتراضي وتُضاف المتغيرات البيئية من لوحة Vercel Settings.
